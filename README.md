# Rational points on the non-split Cartan modular curve of level 121

Code, logs and certificates for the paper

> F. Najman, *Rational points on the non-split Cartan modular curve of level 121* (2026).

**Main result:** `X_ns^+(121)(Q)` consists of exactly 7 points. All of them are CM points, with
discriminants −3, −4, −12, −16, −27, −67 and −163.

Every script runs from the repository root, with Magma V2.30-1:

```sh
magma -b code/<script>.m          # one computation
./run_all.sh                      # everything; logs go to logs/, status to logs/run_all.status
```

`run_all.sh` runs at most 3 Magma processes at a time. The data files that later scripts read
(`data/even_selmer_*.m`, `data/odd_formal_*_p160_data.m`) are regenerated by the scripts that
produce them.

`code/setup.m` is loaded by most scripts. It defines all the objects and checks the identities
of Cor. 4.8 and Sect. 5. `code/original_jmap.m` is the `j`-map of `X_ns^+(11)` from the LMFDB
(modular curve 11.55.1.b.1), and `code/compact_jmap.m` is the same map written as
`(A(x)+B(x)y)/((x−4)(y−5)−11)^11`.

## GRH

GRH is used only to *find* generators of `S`-class groups: `pSelmerGroup` runs after
`SetClassGroupBounds("GRH")`. The generators are then certified unconditionally. Their valuations
outside `S` are checked by factorisation, and their localisations at 11 are checked to be
linearly independent. The dimensions of the global spaces are proved by Lemma 7.1, which is
unconditional.

## Provenance of the computations

* `archive/first_version/` holds the first version of the proof: the manuscript
  `manuscript/xns121.tex` and its ancillary scripts and logs, `ancillary_outputs/`. The large
  global-basis files are omitted there; `data/odd_global_basis_p160_data.m` is the same kind of
  certificate, regenerated.
* `archive/first_version/replay_2026-11-02/` holds the logs of a full rerun of those scripts with
  Magma V2.30-1 on 2 November 2026. The outputs agree with the archived ones, including the six-prime
  sieve data, the odd Selmer certificates and the even Selmer groups (5, 5, 4, 4).
* The even-case computation of the first version used a locally patched copy of Magma's
  `PicnDescent` package; the patch scripts are in `archive/`, and no Magma source is distributed.
  `code/even_selmer.m` replaces it with a computation that uses only public intrinsics. It gives the
  same dimensions and the same intersection properties.
* Independent reconstructions, written separately from the first version:
  - `code/sieve_bruteforce.m`, a brute force over all residues modulo 4356 with globally
    computed functions;
  - `code/even_selmer.m`;
  - `code/cm_lifts.m`, a Frobenius argument that replaces an orbit count which assumed the
    Galois action;
  - `code/genus.m`, in Magma, where the first version used Python;
  - `code/single_place.m`.
* The odd Selmer computation (`code/odd_selmer.m`, `code/odd_directions.m`) is the first-version code
  with paths adapted. It was rerun at precisions 80 and 160, but it was not reimplemented.
